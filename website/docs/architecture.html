Architecture

Independent block editor inspired by Editor.js product behaviour — not a fork of its code.

Folder map

src/                 npm package (the editor)
website/             landing, playground, docs (static HTML/CSS/JS)
docs/                long-form research notes for contributors
tests/               node + browser tests
scripts/             build, check, local server
dist/                library bundles + vendor copies for the site

Core pieces

  • src/core/model.js — validation, IDs, lists, history, stats
  • src/core/editor.js — interactive lifecycle and toolbars
  • src/core/selection.js — caret bookmarks and range helpers
  • src/tools/registry.js — built-in block renderers
  • src/ui/sdk-defaults.js — default dialogs after install

Editing model

Each block owns one or more contenteditable fields. Typing syncs into the model without replacing the active DOM. Structural edits reconcile rows by block id so unchanged blocks keep their DOM identity.

Data format

Documents use { time, version, blocks: [{ id, type, data, tunes }] }. Custom tools use this project’s render / save contract — not Editor.js’s plugin class API.

Contributor research lives in the repo at docs/ARCHITECTURE.md and docs/EDITOR_RESEARCH.md.
