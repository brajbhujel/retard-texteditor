API reference

Import RetardEditor from retard-texteditor. Styles inject automatically. Optional: import 'retard-texteditor/styles.css'.

Create

const editor = new RetardEditor({
  holder: document.querySelector('#editor'),
  data: { blocks: [] },
  defaults: true,
  onChange(instance, data) {}
});

await editor.isReady;
const documentData = await editor.save();

Custom tool

import RetardEditor, { sanitizeHTML } from 'retard-texteditor';

const editor = new RetardEditor({
  holder: 'editor',
  tools: {
    note: {
      title: 'Note',
      icon: 'file',
      render(data, readOnly) {
        return `<div data-note contenteditable="${!readOnly}">${sanitizeHTML(data.text || '')}</div>`;
      },
      save(element) {
        return { text: sanitizeHTML(element.querySelector('[data-note]').innerHTML) };
      }
    }
  }
});

React / Next.js

Create the editor in a client effect after the holder exists. Dynamically import the package, keep the instance in a ref, and call destroy() on cleanup. Never construct it during SSR. Avoid load() on every keystroke — use onChange for form state.
