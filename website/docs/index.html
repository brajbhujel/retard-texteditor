Getting started

Install the package, give it a holder element, and you have a working block editor — styles and dialogs included.

This site is the public face of the package. The library itself lives in src/ and publishes as retard-texteditor.

Install

npm install retard-texteditor

Mount

<div id="editor"></div>
<script type="module">
  import RetardEditor from 'retard-texteditor';

  const editor = new RetardEditor({
    holder: 'editor',
    placeholder: 'Start writing…',
    onChange: async (instance) => {
      console.log(await instance.save());
    }
  });

  await editor.isReady;
</script>

CDN

<div id="editor"></div>
<script src="https://unpkg.com/retard-texteditor/dist/retard-editor.umd.js"></script>
<script>
  new RetardEditor({ holder: 'editor' });
</script>
