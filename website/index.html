retard.

A block editor you install like any other package.

Plain JavaScript. No Editor.js dependency. Mount it in a holder, get structured JSON back.

Open playground Read the docs
Demo reel

Not interactive on purpose. The real thing is in the playground.

Install

Three lines. That is the whole script.

Styles and dialogs ship with the package. You do not need the old workspace shell.

Getting started 
npm install retard-texteditor

import RetardEditor from 'retard-texteditor';

const editor = new RetardEditor({ holder: 'editor' });

Why this exists

Built to drop into your app, not replace it.

Use it in a form, a CMS field, or a writing surface. Keep your own chrome.

Zero npm dependencies

ES modules, TypeScript declarations, and a UMD build for CDN use.

Editor.js-shaped data

Familiar { blocks: [...] } documents without the Editor.js runtime.

Defaults that work

Link, colour, media, and file dialogs are wired unless you opt out.

18 block types

Headings, lists, tables, code, embeds, attachments, toggles, and more.

Export helpers

JSON, HTML, Markdown, and plain text from the same model.

Own your UI

Set defaults: false and handle events when you need custom uploads.
